# BUG-008 Record browser SQL Console and direct DB proxy sessions

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-04-23 16:55

## Description

Gated now records DB Web terminal sessions, but two other database
access paths still do not create recordings:

- the browser SQL Console flow backed by `crates/gated-protocol-http`
  `db_query.rs`
- direct MySQL/Postgres client connections that go through the native
  `gated-protocol-mysql` and `gated-protocol-postgres` proxy servers

As a result, users can execute queries through those paths without any
recording appearing in the admin session recordings list.

Acceptance criteria:

- The exact scope of recording for browser SQL Console sessions is
  defined and implemented.
- The exact scope of recording for direct native MySQL/Postgres proxy
  sessions is defined and implemented.
- Admin recordings can display and inspect the new recording types in a
  useful form.
- Focused verification covers the chosen recording model.

## ActiveForm

Investigating recording coverage for browser SQL Console sessions and
direct native DB proxy connections.

## Notes

- Investigation confirmed the browser DB terminal WebSocket routes are
  recorded, but `crates/gated-protocol-http/src/api/db_query.rs` does
  not currently start or write any recording.
- Investigation also confirmed the direct native database protocol
  crates (`gated-protocol-mysql`, `gated-protocol-postgres`) do not
  currently integrate with the recordings subsystem.
- These two paths have different data shapes from terminal playback, so
  one recording model may not fit both cleanly.
- Implemented SQL-only audit recordings for browser SQL Console
  requests and direct native MySQL/Postgres proxy query requests.
- Scope narrowed to record only the final executed SQL, including
  failed requests, without persisting query results.
- Final implementation groups multiple SQL request events from the same
  browser SQL Console or direct proxy session into a single recording
  and appends one structured SQL audit item per request.
- Verification:
  `cargo check -p gated-protocol-http -p gated-protocol-mysql -p gated-protocol-postgres -p gated-core -p gated-admin`,
  `pnpm exec tsc --noEmit -p tsconfig.json`,
  and `pnpm exec vitest run src/shared/lib/recordings.test.ts`.
