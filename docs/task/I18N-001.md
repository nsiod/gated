## Description

`crates/gated-web/public/locales/{en,zh-CN}/{admin,gateway,client,common}.json` 新增 key 时，容易出现两侧 key 不对齐，运行时 fallback 到 key 字符串。需要机械化校验。

验收标准：
- 新增脚本 `crates/gated-web/scripts/i18n-check.ts`，比较所有 namespace 下 en / zh-CN 的 key 集合；任一侧缺失即退出非零并列出差异。
- 接入 `just lint` 或独立的 `just i18n-check`。
- CI（INFRA-003）调用。
- 现有缺失 key 在本任务一次性补齐（或在不确定翻译时标 `todo: translate`）。

## ActiveForm

添加 i18n key parity 校验脚本并补齐缺失

## Completion

- `crates/gated-web/scripts/i18n-check.ts` — reads every locale under
  `public/locales/*`, flattens each JSON namespace to dot-paths, and
  reports any dot-path present in one locale but missing from another.
  Works for N locales, not just `en` / `zh-CN`; also flags namespaces
  that exist in only one locale.
- Wired as `bun run i18n-check` (package.json) and `just i18n-check`
  (top-level justfile). Added to the `just cleanup` recipe so it runs
  with the rest of the lint gates.
- `CLAUDE.md` Lint & Check table updated.
- Verified locally: 2 locales (en, zh-CN), 3 namespaces (admin,
  common, gateway), all in parity — the planned "一次性补齐缺失 key"
  pass was a no-op.

CI wiring (INFRA-003) will call `just i18n-check` alongside the other
quality gates once that task lands.
