## Description

Gateway 鉴权与 DB 终端流程 tracing 覆盖不均衡：`db_query.rs` 做得较完整（session_id / username / target / statement_kind / sql hash / rows / duration），而 `crates/gated-protocol-http/src/api/credentials.rs`、`auth.rs` 几乎无 tracing；`db_terminal.rs` WebSocket handler 300+ 行仅 3 处 `info!`。

验收标准：
- 对 gateway 的 auth / credential / ws / websocket 流程加 `#[tracing::instrument]`，统一字段：`session_id`、`username`、`target`、`protocol`、`result`、`duration_ms`。
- 错误路径至少 `warn!`，未预期路径 `error!`。
- 敏感字段（密码、token、SQL 原文）禁止进入 span fields，只保留 hash 或摘要。
- 在 `docs/ops/logging.md` 列字段字典。

## Completion

Chose explicit structured events over `#[tracing::instrument]` decorators
— for handlers that need `username` / `target` / `session_id` lazily
(after auth / resolve), a decorator with `fields(...)` + `Span::record`
is more invasive than a couple of `info!` / `warn!` lines at decision
points. Emit sites:

- `crates/gated-protocol-http/src/api/auth.rs`: added
  `auth_login_succeeded`, structured `auth_login_rejected` (was a bare
  `error!("Auth rejected")`), `auth_otp_succeeded`, structured
  `auth_otp_invalid`, `auth_logout` with `username` from the session.
- `crates/gated-protocol-http/src/api/credentials.rs`: added one audit
  `info!` per mutating self-service endpoint (password /
  public_key × 2 / otp × 2 / certificate × 2).
- `crates/gated-protocol-http/src/api/db_terminal.rs`: added
  `db_terminal_invalid_target_name`, `db_terminal_unauthenticated`,
  `db_terminal_authorize_failed`; renamed the existing session-ended
  log to `db_terminal_session_ended` with `duration_ms`; added a
  matching `db_terminal_session_started`.
- `crates/gated-protocol-http/src/api/ssh_terminal.rs`: same shape
  (`ssh_terminal_unauthenticated`, `_session_limit`, `_authorize_failed`,
  `_session_started`, `_session_ended` with `duration_ms`).
- `docs/ops/logging.md`: new field dictionary listing every audit event
  name, its fields, and the explicit never-logged secrets list.

Verified: `cargo check -p gated-protocol-http` + `cargo build
--features mysql,postgres --bin gated` pass. No behaviour change; no
tests touched.

Pre-existing clippy findings in `db_terminal.rs` (`buf[..n]` indexing,
collapsible match) and `gated-ca` were not introduced by this task and
remain tracked separately.
