## Completion notes

- New `shared/components/breadcrumbs.tsx` reading `handle.breadcrumbKey` from `useMatches()`; interpolates `t(key, params)` so `{{id}}` etc. resolve automatically.
- Wired into both `admin-layout.tsx` and `gateway-layout.tsx` headers, replacing the single static app-title text.
- Stripped `: {{id}}` suffix from all `admin:pages.*Detail` and `recording` locale values (en + zh-CN) — showing a UUID in the breadcrumb was noisy and the UUID is already in the URL.

## Followup

- Flat route structure (`targets`, `targets/:id` at same level) means detail pages don't show an intermediate "Targets" crumb — the trail is just `Configuration > Target Detail`. A cleaner hierarchy would require restructuring each resource to `{path: 'targets', children: [index, new, :id]}`. Tracked as followup; sidebar already provides the back path.
- Header could still use a right-side "current user" label for stronger context; currently the sidebar footer shows the user. Leaving header minimal.

## 描述

- header 右侧增加当前用户名 + 环境（`info.external_host`）。
- 调整 header 高度 / 内边距，去掉空白条。
- Gateway 端做对应调整。
