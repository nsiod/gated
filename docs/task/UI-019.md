## Completion notes

- Added `targets.groupFilter` locale (en + zh-CN) — "Group" / "分组".
- `admin/pages/config/targets.tsx`: wrapped the group filter in a labeled toolbar (`<label>Group:</label>` + `<Select>`), with `htmlFor` binding for a11y.
- Fixed the trigger to render the selected group's name (or "All groups") via SelectValue render function, replacing the raw `"all"` display.
- Decided NOT to extract `<ListPageToolbar>` — only Targets has a non-search filter; other lists (Sessions switch, Log filters, Users/Roles/Tickets search-only) have different toolbar needs and a shared component would be premature abstraction.

## 描述

列表页的过滤器、搜索框、主操作按钮目前布局零散：`Targets` 顶部 `all` 下拉无 label、过滤器与 `Create Target` 按钮分两行。需要抽出 `<ListPageToolbar>` 共享组件，让所有列表页对齐。

### 验收标准

- `Targets` 过滤器加 "Group:" 前缀 label。
- 过滤器、搜索框、主操作按钮在同一 toolbar 行。
- 抽出 `ListPageToolbar` 组件，至少 Targets / Users / Roles / Tickets 接入。
- PageHeader (title + description) 与 toolbar 视觉关系清晰。
