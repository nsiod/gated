## 描述

目前 `/ui/client` 只显示 SSH 目标，数据库目标需要从主列表单独点进去用 `/ui/db/...` 页面。参考 JumpServer 的 "My Assets + 顶部 Tab + 中心 Pane" 设计：

- 左侧树：按 group 分组展示所有可连目标（SSH / MySQL / Postgres / Kubernetes），每个条目带类型图标。
- 顶部 Tab 栏：每打开一个连接产生一个 tab，点击切换，X 关闭。
- 中心 Pane：根据 tab 的目标类型分派到不同组件：
  - SSH / Kubernetes → xterm 终端
  - MySQL / Postgres → Schema 浏览器 + SQL 编辑器 + 结果集

### 验收标准

- 从左侧点击任意目标（不限类型）都能在 Tab 中打开，切换不丢状态。
- 数据库 tab 可跑 `select 1;` 并看结果集；SSH tab 可交互。
- 侧栏按 group 分组，未分组目标进 "Ungrouped"。
- 不破坏现有独立路由 (`/ui/ssh/:target`、`/ui/db/...`)，保留兼容。
