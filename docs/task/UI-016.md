## 描述

提升所有列表页（Sessions / Targets / Users / Roles / Tickets / SSH Keys / LDAP / Target Groups）的基础阅读和操作体验。

### 验收标准

- 行 hover 高亮，点击行任意位置进入详情（与 Action 按钮 stopPropagation）。
- 空列表统一接入 `EmptyState` 组件，并提供 "创建第一个 X" CTA。
- 单元格空值用浅色省略符（如 `–`）替代密集的 `—`。
- 分页器只在多页时显示。
- 列表容器宽度评估：在 1440px 视口下不出现两侧大段空白。
