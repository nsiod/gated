# BUG-009 Fix API target gateway list command display

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-04-23 21:40

## Description

The gateway targets list at `/ui` currently renders API target rows as
a direct `https://<external_host>` link in the Actions column. That is
misleading because API targets are reached through Gated with the
`X-Gated-Target` header rather than by opening the gateway host
directly in a browser.

Acceptance criteria:

- API target rows no longer present the gateway host as a direct
  clickable endpoint.
- The UI presents a copyable curl example that shows the required
  `X-Gated-Target` header for API targets.
- WebAdmin target rows keep their current direct-link behavior.
- Focused verification covers the chosen UI behavior.

## ActiveForm

Investigating and fixing misleading API target command display in the
gateway targets list.
