## 描述

侧边栏四个分组（Monitoring / Configuration / Security / System）当前只靠 separator + 灰色 label 区分，缺乏视觉锚点；当前激活项的高亮对比度也偏弱。

### 验收标准

- 分组 label 加配色或 icon。
- 激活项使用 primary 背景 + 高对比 foreground。
- 暗色 + 亮色两套主题下都验证对比度（WCAG AA）。
- 折叠态保留 tooltip。
