# BUG-005 Fix admin log message overflow

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-04-23 15:20

## Description

The admin audit log page at `/ui/admin/log` lets long values in the
Message column force the table wider than the viewport. On narrow
screens this causes horizontal page overflow and requires side
scrolling just to read the page.

Acceptance criteria:

- The Message column wraps long content instead of forcing the table
  beyond the viewport width.
- Existing timestamp, username, and session ID rendering stays
  unchanged.
- The fix stays limited to the admin log page unless investigation
  proves a shared component change is required.

## ActiveForm

Investigating and fixing long-message overflow on the admin audit log
page.

- **blocked by**: (none)
- **blocks**: (none)

## Notes

- Investigation traced the page to
  `crates/gated-web/src/features/admin/pages/log.tsx`.
- The shared table primitive in
  `crates/gated-web/src/shared/components/ui/table.tsx` applies
  `whitespace-nowrap` to every `TableCell` by default.
- The admin log Message cell currently renders `entry.text` with only
  `text-sm`, so long unbroken strings inherit `nowrap` and expand the
  table width.
- A similar log table exists in
  `crates/gated-web/src/features/admin/pages/config/target-detail.tsx`
  and may need a follow-up if the same behavior is confirmed there.
- Implemented a local override in
  `crates/gated-web/src/features/admin/pages/log.tsx` so the Message
  cell uses `whitespace-normal break-all` instead of the shared table
  default `whitespace-nowrap`.
- Verification:
  `pnpm exec eslint src/features/admin/pages/log.tsx` (passes with two
  pre-existing warnings in the file: `react/prefer-use-state-lazy-initialization`
  and `react/no-array-index-key`) and
  `pnpm exec tsc --noEmit -p tsconfig.json` in `crates/gated-web`.
