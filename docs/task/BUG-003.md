# BUG-003 Fix recording detail text overflow

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-04-23 13:48

## Description

The admin recording detail page at `/ui/admin/recordings/:id` still has narrow-screen overflow risks after the player viewport fix. Long recording names in the page header and long metadata values can exceed the viewport width and reintroduce horizontal scrolling.

Acceptance criteria:

- Long recording names wrap within the page header on narrow screens.
- Long metadata values wrap within the metadata card without page-level horizontal overflow.
- The fix stays limited to the recording detail route and the shared page header behavior it depends on.

## ActiveForm

Fixing recording detail text overflow on narrow screens.

## Dependencies

- **blocked by**: (none)
- **blocks**: (none)

## Notes

- Investigation found `PageHeader` does not currently allow its title column to shrink, so long `recording.name` values can stretch the layout.
- The recording metadata grid already handles `session_id` with `break-all`, but the other metadata values do not apply wrapping constraints.
- Updated `shared/components/page-header.tsx` so the title column can shrink and long titles/descriptions wrap instead of forcing the page wider than the viewport.
- Updated `features/admin/pages/recording.tsx` so the metadata card can shrink and metadata values wrap with `break-words`; the `session_id` field keeps `break-all`.
- Verification: `pnpm exec eslint src/shared/components/page-header.tsx src/features/admin/pages/recording.tsx` and `pnpm exec tsc --noEmit -p tsconfig.json` in `crates/gated-web` both pass.
