### `user-detail.tsx` split

`user-detail-parts/`:
- `otp-uri.ts` (+ unit tests) — RFC 4648 base32 encoder + `otpauth://`
  URI builder. Was inline in user-detail.tsx.
- `edit-user-card.tsx` — username / rate-limit / description form.
- `ldap-card.tsx` — LDAP link state + auto-link / unlink actions.
- `passwords-tab.tsx` — list + add + delete password credentials.
- `public-keys-tab.tsx` — list + add + delete public-key credentials.
- `otp-tab.tsx` — QR-URI issuance + delete OTP credentials.
- `certificates-tab.tsx` — issue + revoke client certs + copy PEM.
- `sso-tab.tsx` — list + add + delete SSO credentials.
- `api-tokens-tab.tsx` — create + list + revoke bearer tokens.
- `roles-tab.tsx` — add / remove role assignments.

Main file (`user-detail.tsx`) now just: data fetch, loading + not-
found states, `<PageHeader>`, two-column top row
(EditUserCard + LdapCard), and the 7-tab layout.

### `database-console.tsx` split

`shared/components/sql-console/`:
- `sql-history.ts` (+ unit tests) — localStorage-backed query history
  with per-target scoping and MAX truncation.
- `error-message.ts` — shared error-extraction helper for SQL Console
  failures (JSON `{ error }` body, raw text, Error fallback).
- `schema-tree.tsx` — `SchemaNode` + `TableNode` rendering nested
  schema/table/column explorer.
- `result-grid.tsx` — sortable `<ResultGrid>` with `formatCell` kept
  private to the module.

Main file (`database-console.tsx`) now just: state + mutations +
editor binding + layout shell.

## Deferred — `target-form.tsx`

976 lines. Structure: `TargetFormFields` alone is ~587 lines and
branches on `TargetKind` (Ssh / MySql / Postgres / Kubernetes / Api /
WebAdmin), with kind-specific sub-forms + a nested `TlsFields`
block. Splitting it well needs per-kind files
(`target-form-parts/{ssh,mysql,postgres,kubernetes,api}.tsx`) plus a
dispatch table and cautious prop-plumbing for the RHF form instance.
That's its own dedicated task — tracked as a follow-up; the pattern
established by `user-detail-parts/` is the template.

## Description

以下前端页面单文件行数过大，维护成本高、审查难度高：

- `crates/gated-web/src/features/admin/pages/users/user-detail.tsx`（1400+ 行）
- `crates/gated-web/src/features/admin/pages/config/target-form.tsx`
- `crates/gated-web/src/features/gateway/pages/sql-console.tsx`

验收标准：
- 每个页面主文件 < 500 行；tab / 子表单 / 弹窗 / hook 抽出独立文件，放入同级 `components/` 或 `_components/` 目录。
- Hook 抽到 `hooks/`，纯函数抽到 `utils/`。
- 保留对外 URL / 行为不变；相关的 vitest（TEST-001）对新组件做烟雾测试。
- `just lint && just typecheck && bun run build` 通过。
