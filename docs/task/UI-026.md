## Outcome — already in place before this PR

Audited the shared UI primitives and found several AC items were
already handled by Base UI / shadcn or the shared components:

- **Focus rings**: `shared/components/ui/button.tsx` has
  `focus-visible:border-ring focus-visible:ring-[3px]
  focus-visible:ring-ring/50` baked into `buttonVariants`. Every
  component routed through `<Button />` inherits it.
- **Dialog `aria-labelledby` / `aria-describedby`**: Base UI
  `Dialog.Title` and `Dialog.Description` wire those
  automatically on the Popup when mounted, so any Dialog that
  renders `<DialogTitle>` + `<DialogDescription>` is compliant.
- **Dialog close button**: `<DialogContent>` renders a built-in
  close with `<span className="sr-only">Close</span>`.
- **Mode toggle / Language toggle / Copy button**: all already use
  `<span className="sr-only">...</span>` on their icon-only
  triggers, so screen readers get a name.

## Changes made

- **DataTable sort headers** (`shared/components/data-table.tsx`):
  - Sortable `<th>` now carries `aria-sort="ascending|descending|none"`.
  - Header content migrated from `<div onClick>` to `<button type=
    "button">` — keyboard activation works, Tab order is correct,
    and a nested `<span className="sr-only">` announces the current
    sort state via three new i18n keys in `common.table`:
    `sortedAsc` / `sortedDesc` / `sortUnsorted` (en + zh-CN in
    parity — `bun run i18n-check` clean).
- **`user-detail-parts/*`** — seven credential tabs: each Trash2
  icon-only button gained `aria-label={tc('actions.delete')}`.
- **`client-layout.tsx` SidebarToggle** — `aria-label="Toggle
  sidebar"` + `aria-expanded={open}` on the trigger (tooltip text
  alone wasn't reliable for screen readers).
- **`features/admin/pages/config/targets.tsx`** — row-action icon
  buttons (edit + delete) got `aria-label` sourced from
  `common:actions.{edit,delete}`.
- **`@axe-core/react` dev integration** — `src/main.tsx`
  conditionally imports and runs `axe-core` when
  `import.meta.env.DEV`. The dynamic import + env guard keeps the
  ~200 KiB payload out of production bundles; verified
  `index-91defUoi.js` stayed at 838 KB (was 838 KB pre-change) and
  `grep axe` on the built chunk returns nothing.

## Description

对 `crates/gated-web/src/features/**` 的粗查显示几乎没有 `aria-label` / `aria-describedby` / `role` 等可访问性属性。shadcn/ui（Base UI）提供基础语义，但自定义 Dialog / Form / IconButton 仍需显式标注以满足 WCAG 2.1 A 级。

验收标准：
- 所有 IconButton（仅图标无文本的按钮）加 `aria-label`。
- Form label 显式 `htmlFor` → `<input id>`，或用 `<Label>` 包裹。
- Dialog 有 `aria-labelledby`、`aria-describedby`。
- Table 有 `<caption>` 或 `aria-label`；排序按钮标注当前方向。
- 键盘聚焦环可见（tailwind `focus-visible:` 样式统一）。
- 引入 `@axe-core/react` 在 dev 模式中在 console 提示违规（不阻断）。
- 覆盖 admin + gateway + client workspace。
