## Completion notes

- DataTable: added `enableRowSelection` + `renderBulkActions(selected, clear)` props, plus internal `rowSelection` state and a prepended `__select` checkbox column.
- Header checkbox toggles all page rows; supports indeterminate state via Base UI Checkbox's `indeterminate` prop.
- Row checkboxes get `data-stop-row-click` so clicking them does not trigger row navigation.
- Bulk actions bar (sticky primary-tinted bar) renders above the table when rows are selected; shows `{{count}} selected`, the consumer's actions, and a Cancel button that clears selection.
- Targets page: wired bulk delete — opens a ConfirmDialog, fans out `deleteTarget` via `Promise.allSettled`, reports success/partial counts via sonner toast, clears selection on success.
- Added `common:table.selectedCount` + `admin:targets.bulkDelete*` locale keys in en + zh-CN.

## 描述

当前列表无 checkbox 多选，删除 / 移入分组 / 改角色等只能逐行操作。需要为 DataTable 接入 row selection，并在选中时暴露 bulk actions。

### 验收标准

- DataTable 接入 row selection（TanStack Table v8 自带能力）。
- 选中时列表顶部出现 selected count + bulk actions 区。
- Targets / Users / Sessions 至少接入：批量删除、批量分组（Targets）、批量关闭（Sessions）。
- 后端无 batch endpoint，前端 fan-out 请求并汇总成功 / 失败。
