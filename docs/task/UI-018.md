## 描述

Gateway 端 `target-list.tsx` 当前只为 SSH 行展示连接命令和 `Open Terminal` 按钮，MySQL / Postgres / Kubernetes 行右侧 Actions 列空白。需要为每种类型提供对应的 "如何连接" 提示。

### 验收标准

- MySQL 行展示 `mysql -h <host> -P <port> -u <user> -p` 命令 + 复制按钮。
- Postgres 行展示 `psql 'postgres://<user>@<host>:<port>'` 命令 + 复制按钮。
- Kubernetes 行展示 kubeconfig 复制按钮（或下载）。
- Web Admin 行展示 "Open" 按钮，新窗口打开 admin URL。
- 视觉布局与现有 SSH 行一致。
